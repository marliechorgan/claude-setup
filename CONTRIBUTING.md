# Contributing

Bug reports, cases where a skill steers wrong, and new evals are the most valuable contributions. Problems with the safety guards belong in [claude-safety-guards](https://github.com/marliechorgan/claude-safety-guards).

Before opening a pull request, run the checks in [CLAUDE.md](CLAUDE.md) (they also run automatically on every push). Keep examples invented: no real names, companies, paths or command history.

By contributing you agree your contribution is licensed under MIT.

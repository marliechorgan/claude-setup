# Contributing

Bug reports, guard bypasses and new test cases are the most valuable contributions. See [SECURITY.md](SECURITY.md) for bypasses.

Before opening a pull request, run the checks in [CLAUDE.md](CLAUDE.md) (they also run automatically on every push). Every change to a guard needs a test case that fails without it. Keep examples invented: no real names, companies, paths or command history.

By contributing you agree your contribution is licensed under the licence of the file you change (MIT, or AGPL-3.0-or-later for `plugins/safety/guards/command-guard.sh`).

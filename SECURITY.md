# Reporting a security problem

- **A problem in a skill or its scripts:** please report it privately through GitHub's *Report a vulnerability* button on the Security tab, so it can be fixed before it's public.
- **A way past the safety guards:** report it in [claude-safety-guards](https://github.com/marliechorgan/claude-safety-guards).

Include what you did, what you expected, what happened, and your OS and shell.

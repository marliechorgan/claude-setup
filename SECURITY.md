# Reporting a way past the guards

Found a command that gets past a guard in `plugins/safety`, or a guard that blocks ordinary work? That's the most useful thing you can send.

- **A bypass that could hurt someone's machine:** please report it privately through GitHub's *Report a vulnerability* button on the Security tab, so it can be fixed before it's public.
- **Anything else** (a false block, a missed case that's already widely known): open an issue with the *Guard bypass or false block* template.

Include the exact command or tool call, what you expected, what happened, your OS and shell, and the guard's message if there was one. Every fixed report becomes a test case.
